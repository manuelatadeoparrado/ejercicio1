# Registro de sesiones

Este archivo conserva el historial de trabajo para poder retomar el proyecto en futuras conversaciones.

## Protocolo obligatorio
- Al comenzar una sesión, leer este archivo y después `personalidad.md`, `contexto.md` y `criterio.md`.
- Revisar en GitHub el estado real de los archivos antes de hacer cambios.
- Al terminar cada sesión de trabajo, añadir una entrada con fecha, cambios realizados, decisiones confirmadas, verificaciones y tareas pendientes.
- Registrar únicamente acciones realmente completadas. Diferenciar propuestas de decisiones aprobadas.
- Si una sesión no produce cambios, registrar los acuerdos y el siguiente paso cuando sea útil.
